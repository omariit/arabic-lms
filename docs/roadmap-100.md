# خطة الوصول إلى جاهزية 100% — مُقْرِئَة

الهدف: تجربة مترابطة من الطالبة → المعلمة، بلا شاشات ميتة، بلا ميزة مكرّرة في مكانين، وكل
وظيفة قابلة للفحص آليًا. يُحدَّث هذا الملف مع كل مرحلة.

## المبدأ الحاكم
> كل شيء يحدث للطالبة **يجب أن يظهر للمعلمة** في مكان واحد معروف، وكل ميزة لها **مكان واحد فقط**،
> وكل عنصر يمكن **حذفه/تعطيله/إظهاره**، وكل مسار له **اختبار آلي**.

---

## المرحلة 1 — تنقّل متّسق (لا رجوع إلى الصفحة الرئيسية)
- [ ] 1.1 مستخدمة مسجّلة تفتح `/` → تُحوَّل فورًا إلى لوحتها (`/dashboard` أو `/admin`)، مع `?preview=1` للإدارة لمعاينة الصفحة.
- [ ] 1.2 شعار/روابط الموقع في الصفحات العامة → لوحة الدور وليس الصفحة الرئيسية.
- [ ] 1.3 لوحة الطالبة: حالة «لا مقررات» حقيقية + طلبات الانتساب المعلّقة + مقررات مقترحة + رابط `/courses` (لا `/`).
- [ ] 1.4 شريط تنقّل موحّد للطالبة (لوحتي · المقررات · رسائلي · خروج) في كل صفحات الطالبة.

## المرحلة 2 — صندوق الواجبات (إصلاح «المعلمة لا ترى تسجيل الطالبة»)
- [ ] 2.1 `/admin/inbox`: كل رسائل الدروس في كل المقررات، غير المقروء أولًا، مع عدد لكل درس.
- [ ] 2.2 عدّاد مستقل في الشريط للواجبات (الآن يظهر داخل «الرسائل» بلا مكان يفتحه).
- [ ] 2.3 تصفير `staffUnread` عند فتح المحادثة فعلًا + إشعار «تم القراءة».
- [ ] 2.4 من صفحة المقرر: زر «واجبات الدرس» وشارة عدد التسليمات لكل درس.

## المرحلة 3 — تسميات وتسجيلات
- [ ] 3.1 إزالة التكرار: «التسجيلات» مرّتين في القائمة («تسجيلات الحصص» و«طلبات الانتساب»).
- [ ] 3.2 صفحة التسجيلات: حالة فراغ مفهومة + سبب + زر مباشر إلى الاستوديو، وفلتر (الكل/الخاصة بي).
- [ ] 3.3 حذف التسجيل من القائمة مع تأكيد، وتعطيل/تمكين ارتباطه بالدرس.

## المرحلة 4 — الاختبارات
- [ ] 4.1 `shuffleQuestions` و`shuffleOptions` على مستوى الاختبار (تفعيل/إلغاء من المعلمة).
- [ ] 4.2 تخزين ترتيب العرض داخل المحاولة كي يبقى التصحيح والمراجعة متطابقين.
- [ ] 4.3 نشر/تعطيل الاختبار + حذفه من قائمة الاختبارات.

## المرحلة 5 — استوديو العرض (صور/PDF + تكبير ورسم)
- [ ] 5.1 رفع صورة أو PDF وعرضها على لوحة داخل الاستوديو.
- [ ] 5.2 تكبير وسحب ورسم بالإصبع/الفأرة، ويُسجَّل كل ذلك داخل الفيديو.
- [ ] 5.3 مشاركة التسجيل في الدرس أو في البث بضغطة واحدة.

## المرحلة 6 — البث المباشر
- [ ] 6.1 إرفاق الملفات (صورة/PDF/صوت) في محادثة البث — نفس مكوّن المرفقات المستخدم في التسجيل.
- [ ] 6.2 المشاركة في الدردشة والملفات مع كل المشاركات، وحفظها بعد انتهاء البث.
- [ ] 6.3 لوحة المعلمة: بدء/إيقاف البث، عدد الحاضرات، ومن انضم.

## المرحلة 7 — فحص ونشر
- [ ] 7.1 اختبارات وحدة (ترتيب الأسئلة، صلاحيات المرفقات، عدّادات القراءة).
- [ ] 7.2 Playwright: طالبة/معلمة لكل مسار جديد + فحص شامل للشاشات.
- [ ] 7.3 وكيل مراجعة مستقل (كطالبة وكمعلمة) يوثّق أي كسر.
- [ ] 7.4 نشر staging → فحص → نشر إنتاج → فحص للقراءة فقط.
